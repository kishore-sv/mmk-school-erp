# Navigation and pages

The sidebar has these 17 sections. Nested links are real routes. Module records are not implemented yet; each page states what will be managed there later.

1. `/dashboard`
2. `/school-setup` — profile, academic years, shifts, working days, calendar
3. `/academic-management` — classes, subjects, grading
4. `/student-management` — directory, enrollment
5. `/admission-management` — applications, enquiries
6. `/staff-management` — directory, departments
7. `/parent-management` — directory
8. `/timetable-management` — timetables, rooms
9. `/attendance-management` — students, staff
10. `/examination-assessment` — examinations, report cards
11. `/learning-classroom` — homework, materials
12. `/fee-management` — structures, collections
13. `/transport-management` — routes, vehicles
14. `/calendar-events` — events, holidays
15. `/notifications-communication` — announcements
16. `/reports-analytics` — catalogue
17. `/settings-permissions` — security, audit

Also:

- `/login`
- `/forgot-password`
- `/reset-password`
- `/account/password`
- `/notifications` — empty state
- `/school-setup/profile` — editable school profile and branding

The header notification control opens `/notifications`. It does not invent notification records.
