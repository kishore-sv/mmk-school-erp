# Accessibility landing

- Use landmarks (`header`, `nav`, `main`, `footer`) and one `h1` per page.
- Keep keyboard focus visible. Do not rely on hover alone.
- Label every input. Associate errors with `aria-invalid` and text.
- Respect `prefers-reduced-motion` for any motion.
- Give images and the logo meaningful text or `aria-label`.
