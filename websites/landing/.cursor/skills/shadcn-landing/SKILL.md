# shadcn landing

- Theme tokens live in `src/app/globals.css`. Do not replace the palette or add gradients.
- Components are in `src/components/ui` (base-nova / Base UI). Compose them; do not invent a second button system.
- Desktop navigation uses `NavigationMenu`. Mobile navigation uses `Sheet`.
- Forms use `Field`, labelled controls, and visible errors.
- Also follow the repo skill at `.agents/skills/shadcn` when it applies.
